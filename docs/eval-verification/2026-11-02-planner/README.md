## 仍存在的問題

- **單位換算錯誤（10 倍）**：`2330-future-revenue-2030` 正確拒答，但附帶的 2026Q1 營收仍寫成「新台幣 1,134.10 億元」；來源表頭單位為「新台幣十億元」，正確為 11,341 億元。此題只評拒答行為，因此仍判 PASS。先前正式 run 也有相同錯誤，屬生成問題，尚未修正。
- **citation_coverage 下降**（0.85 → 0.66）：回答中有較多數字句未附引用，需另查。
- **KI-004**：政策題需語意判斷（LLM judge），規則式評分無法處理。
