## 環境與驗證範圍

獨立資料庫 `equitylens_risk_profile_r11_eval`，ParadeDB 容器專案 `equitylens-runtime`，僅 loopback 55432；Redis DB 14，API 5545。啟動前檢查容器標籤與埠，未連正式 DB。行情由既有合成 fixture 產生，as-of 2026-11-03，基準價格與持股固定；與歷史能取得 snapshot 的題逐一核對日期、代號、股數、價格相同。其餘題不聲稱已用歷史快照直接核對。基準資料從本機固定 benchmark 提供，沒有行情 API 費用。

本人 API 的讀寫／匿名拒絕／其他帳號隔離／注入 userId 拒絕／W3 漏答拒絕／手動覆寫擦除回答／刪除實體紀錄另有真實 HTTP 驗證。AI eval 只保存合成手動偏好，未向 LLM 提供問卷回答。

每題保留回答與 gate 結果；工具只讀、持倉交易 before/after 比較、情境數值以 Python 獨立重算。本輪 Luna 配置見 risk-profile.json 的 provider_config：medium、100000 輸入／5000 輸出 token，上限高於較早 low 設定的 60000／2500；這是隔離驗證配置，不是正式站已切換。一般文字數字使用正式程式 gate，不是另一個獨立語意裁判；質化建議仍需人工判讀。

R1 發現查詢曆日與實際共同交易日期不同，修正為綁定同一凍結輸入的交易區間。R2 人工檢查發現 profileFit 已存在但模型仍說 unavailable，因此加強新題評分與 gate；不把 R2 的初步機器通過當成完成。R3 完整 9/14、1/2，查出新問題未進入一次修訂，以及大型分析尾端比較被截斷。R4 中止，修正回饋沿用舊假設、未具體說明分段的問題。R5 中止，移除重複提示以符合淨縮減要求；中止時未結算預留仍保守計入成本。R6 完整 7/14、2/2。R7 修正同輪並行分析快取後完整 8/14、2/2，波動率題 1/1；模型仍有 JSON 格式與數字／口徑錯誤。使用者指定接回 Luna；R8 為 Luna 首輪，10/14、2/2、波動率 1/1。R9 修正原生拒絕回饋與過時提示視窗，原 14 題 8/14、偏好原分 1/2、波動率 0/1。R9 發現 (a) 新增 RP 評分器漏認分析工具內嵌偏好，修正為 2-rp3 後僅該新增套件離線重算為 2/2；(b) 參考門檻比較誤當情境比較；(c) 內嵌偏好漏附固定來源聲明。R10 修正這些問題並以 100000 輸入 token 預算跑完整套件，仍有漏引用及參考門檻後帶數字的分類問題。R11 補齊明確門檻值的分類測試，並改用 medium 推理／5000 輸出 token；每 run 6 輪、US$0.10 不變。未累加投組提示規則；數字、引用與比較方向仍必須驗證。所有中止與失敗均保留，不改寫歷史結果。
