# EquityLens 風險檢定有限樣本研究

日期：2026-11-06。研究限定；未更動生產程式、模型或判定門檻。

## 可以採用的結論

- 共完成450條主研究路徑：4個案例各100條，加完整 refit21 流程50條。另完成10,000條正確 iid VaR 虛無路徑，獨立檢查漸近 coverage/independence 門檻。
- 已知正確條件分布的檢定大小，與有限歷史樣本庫、波動估計、重估流程的實務拒絕率，必須分開解讀。後者不是已證明條件預測正確時的型一錯誤率。
- 在指定單資產refit252/21流程中，C_ES5在95%/97.5%/99%層級的拒絕率為10%/14%/12%；97.5%為7/50，95% Wilson區間6.95%–26.19%。99% Kupiec為8/50=16% [8.34%,28.51%]。相反，rolling iid與真波動oracle的U_ES各層級均為0/100 [0%,3.70%]。這些範圍只屬於此DGP與流程，不能轉成通用p-value修正。
- 10,000路徑核對顯示，T=1317 時 production Christoffersen independence 在95%、97.5%、99% VaR的5%名目門檻下，實際拒絕率為6.78%、1.93%、1.23%。因此不拒絕不等於通過，99%層級尤其不能當作有力的獨立性證據。Kupiec 的4.77%、5.27%、4.92%區間皆涵蓋5%。
- 本研究不提供通用修正係數，不更換正式臨界值，也不能認定某個 challenger 較佳。

## 主研究設計與比較口徑

比較工作 protocol 為 top10 strict、snapshot/等權、共同 OOS 2021-06-04 至2026-11-04，共1317日。本研究只配對樣本長度及檢定口徑，不使用該價格資料，亦不驗證 seed 修復結果。

- 每條模擬路徑1317個預測日；每個FHS樣本庫252日，10,000個預測抽樣；forecast atoms保留float32，統計量float64。
- 95%、97.5%、99%信心水準；ES使用原始 DE independent-daily-rank Monte Carlo U_ES/C_ES(1,5)，每次inner=2000；最小p值及步長為1/2001≈0.00049975，拒絕規則p≤0.05。
- DGP：單資產、標準化t5創新；GARCH(1,1)百分比單位omega=.05、alpha=.05、beta=.90；2000日burn-in。iid案例沒有GARCH波動。
- 正確條件分布控制：真實條件波動與t5法則已知，直接以解析 t.cdf(z/sqrt(3/5),5) 計算PIT，參考分布為每日獨立Uniform(0,1)。不估參數、沒有有限樣本庫。
- fresh_iid每日重新生成252個歷史創新及1個新觀測；rolling_iid使用重疊252日創新庫；rolling_garch_oracle知道真實波動，但仍只有有限滾動創新庫；refit21完整重用生產 VT-GARCH估計、每日更新殘差/波動及21日重估。
- 比較研究的756日共同比較暖機是為容納所有候選窗口；252日基準只估最近252日。本研究同樣使用252日估計窗，加DGP burn-in，沒有把其誤寫為756日估計。
- 主研究沿用原始 null_size 的獨立case/rep及DGP/bank/inner種子，refit抽樣沿用production deterministic_seed。比較工作另採共同每日uniform種子，因此此處對齊機率法則與檢定口徑，不聲稱逐抽樣位元相同或跨案例配對推論。
- VaR使用生產Kupiec coverage及Christoffersen independence函數。後者不是聯合conditional-coverage檢定。保留原始nearest-rank及浮點ceil邊界，strict actual < VaR由PIT精確重建。

### 解讀限制

1. 外層100或50仍是小型研究。若5/100拒絕，95%區間約2.15%–11.18%；若0/50拒絕，仍有約7.13%的上限。零拒絕不能證明零型一錯誤或模型正確。
2. rolling與refit有重疊樣本庫及估計誤差，independent-daily-rank虛無不描述完整流程。拒絕率偏低也可能代表檢定保守，不能解讀為方法更穩健或更有力。
3. U_ES是一側右尾；C_ES是自相關統計的右尾。C_ES拒絕本身不指示低估或高估方向。內層Monte Carlo也有誤差，這些外層Wilson區間並非全家族同步區間。
4. 未做替代假設下的power研究；未涵蓋多資產相關、copula、GJR、EVT、組合權重或整個窗口/重估網格，也未校準AS Z1/Z2、McNeil–Frey、FZ loss比較bootstrap、模型選擇或多重比較程序。
5. fresh_iid理論依賴連續可交換秩及獨立每日樣本庫；float32碰撞/重複值仍按實際程式處理。不以個別100路徑控制的偶然偏離認定普遍失準。

## 驗證、耗時與重現

- 10項新增針對性測試通過：壓縮/完整DE p-value與統計量一致、PIT重建strict VaR breach涵蓋ties/極端值、5種案例種子重現、undefined及Wilson邊界。不是生產全測試套件聲明。
- 主研究全部450筆checksum、計數、索引、summary重算及source hashes通過；每案例前2條完整重播，共10條，統計量、p值及PIT checksum完全一致。
- 額外VaR向量公式對300條路徑（含全hit、全miss）逐一核對生產函數，最大絕對誤差<1.7e-16。初次輸出summary遇NumPy int序列化問題，僅修正int型別後重跑；修正前後完整p-value檔SHA256相同，統計結果未改。
- 主研究計算時間 363.19秒；精確驗證 10.63秒；前置11路徑T=504小試3.51秒。額外10,000路徑純模擬/彙總區段 0.203秒，不含啟動及公式交叉核對。實際耗時受同機並行工作影響。
- Python/套件版本、完整種子、各source SHA256與每案例耗時見manifest；原始production sources未修改。

在研究包根目錄，使用既有Python3.12依賴環境，先將EquityLens.Mathematics/src與risk_calibration加入PYTHONPATH，設OMP_NUM_THREADS=OPENBLAS_NUM_THREADS=MKL_NUM_THREADS=1：
