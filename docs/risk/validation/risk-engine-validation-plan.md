# 風險引擎驗證計畫：統計驗證 → Ensemble → 資料管線 → 五年回測

> 日期：2026-07-26
> 性質：task spec（供 Codex 執行）
> 範圍：`run_backtest.py` 研究分支。不動正式 risk-worker API、不動 main、遠端 PostgreSQL 用完停回原狀。

---

## 0. 背景與現況

已完成三輪樣本外回測（20 檔 0050 成分股、市值正規化權重、252 日 lookback、471 個預測日、每日 5,000 次 joint-vector bootstrap、每 21 日重估）：

| 模型 | 95% 違約率 | 95% QL | 99% 違約率 | 99% QL | 99% ES ratio |
|---|---|---|---|---|---|
| MVEWMA-FHS | 4.88% | 0.002315 | 1.91% | 0.000771 | — |
| GARCH-t + joint FHS | 4.88% | 0.002242 | 0.85% | 0.000764 | 1.275 |
| GJR-GARCH-t + joint FHS | 5.31% | 0.002212 | 1.27% | 0.000778 | 1.207 |

**目前所有模型間差異都沒有配對顯著性檢定。** 違約差 1–2 次、QL 差 1–4%，在 471 個樣本外日下可能全是噪聲。本計畫的核心原則：**先補統計證據，再談架構決定。**

### 常設規則（本檔案所有任務適用）

1. 所有模型間差異陳述必須附檢定或明確標註「未檢定」。
2. 不許為讓某模型勝出調參（窗寬、重估頻率、QL 定義維持現狀）。
3. 差距未達顯著時依 parsimony 選簡單模型。
4. 暫不實作「95% GJR / 99% GARCH 分層」的任何程式碼。

## Phase 0：等權重診斷回測（最高優先，插隊）

### 動機
現行市值正規化權重下台積電佔 67.05%，HHI ≈ 0.455，**有效投注數 ENB ≈ 2.2**。這代表目前回測主要在驗證「台積電單名 + 邊際貢獻」，多變量機制（EWMA covariance、joint FHS 相依結構）對 VaR 的影響被壓到二階。三模型指標接近，可能不是模型一樣好，而是**測試台測不出差異**。

等權重（每檔 5%，ENB = 20）下組合要崩必須多檔聯合崩，才是 covariance 動態與尾部相依的考場。

### 任務
- 用完全相同的資料、日期、seed 規則，把權重向量換成等權重，三模型重跑完整回測。
- 角色定位：等權重 = 診斷用 benchmark（模型選擇）；市值權重 = 生產現實檢查。兩者並存，不互相取代。

### 產出
- 等權重版完整指標表（同現有格式）。
- 一段對比判讀：等權重下模型間差異是否放大（預期會）。若放大，先前市值權重下的「打平」結論需標註為「測試台鑑別力不足所致」。

---

## Phase 1：統計驗證（不改模型）

### Task 1.1：Diebold-Mariano 檢定
- 對三模型的每日 quantile loss 序列做兩兩配對 DM 檢定（MVEWMA vs GARCH、GARCH vs GJR、MVEWMA vs GJR），95%/99% 各一組，共 6 個。
- QL 差異序列有違約群聚，標準誤用 HAC 或 block bootstrap（block 長度 21），不得用 i.i.d. 假設。
- 判讀：p < 0.10 才算有差異；否則打平，依 parsimony 處理。
- 等權重與市值權重兩組資料都要做。

### Task 1.2：子期間穩定性
- 471 個預測日切前後兩半，各自重算三模型違約率、Kupiec p、QL。
- 「95% GJR 贏、99% GARCH 贏」的排名必須在兩半都成立才算穩定；翻轉即標記為噪聲。

### Task 1.3：違約重疊分析
- 確認 99% 下 GARCH 的 4 次違約是否 ⊆ MVEWMA 的 9 次。
- 列出 MVEWMA 多違約的日期、當日兩模型 VaR 預測值與實際損失。

---

## Phase 2：Ensemble 候選（新實驗，不寫新模型）

### 動機
對稱 GARCH 微保守（99% 違約 0.85%）、GJR 微過度保守（1.27%）。兩個預測分布 50/50 混合，違約率預期落在兩者之間（95% ≈ 5.1%、99% ≈ 1.06%），QL 可能同時優於兩個母模型（組合預測的變異數縮減）。

### 任務
- 對稱 GARCH-t 與 GJR-GARCH-t 的每日 predictive CDF 直接平均，作為第四候選，跑相同回測評估。
- 等權重與市值權重兩組都做。
- 若 ensemble 在兩個水準的 QL 都贏單一模型，則「分層選模型」需求消失，報告中明確陳述。

---

## Phase 3：Variance Targeting

- GARCH-t 與 GJR 擬合改 variance targeting：ω = σ̄²(1−α−β)（GJR 為 ω = σ̄²(1−α−β−γ/2)），少估一參數。
- 252 日窗的 GARCH-MLE 有已知的 persistence 高估小樣本偏誤，此為結構性修法，優於事後 guardrail。
- 驗收：近單根（persistence ≥ 0.995）擬合比例 < 5%，且回測指標無顯著劣化 → 成為預設。
- 輸出：近單根次數前後對比（現況 GARCH 63 次、GJR 54 次）+ 完整指標表。

## Phase 4：Adjusted Close 資料管線（**僅規劃，禁止實作 production code**）

### 背景
所有 20 檔缺 adjusted_close；已發現 2327 國巨 2025-08-25 拆股造成 -73.8% 假報酬（已排除，改 2886）。假報酬會永久留在 filtered residuals 中撐厚尾部，且對 copula 類估計的傷害大於 FHS。此管線是五年回測的硬閘門。

### 規劃交付（設計文件 + 工項拆解與估時）
1. **資料源比較**：TWSE/TPEx 公開資訊（除權息、減資、分割調整因子）、FinMind、yfinance `.TW` Adj Close。yfinance 需抽查 5 檔驗證覆蓋率與正確性。
2. **調整方法**：backward adjustment 因子鏈公式；邊界案例（減資、分割、現金股利）。論證風險模型應用 total return 還是 price return。
3. **3037 僅約三年歷史**的選項分析：排除（19 檔）/ 縮短共同區間 / 替換同類股，各選項對五年回測的影響。
4. **Point-in-time 成分股**：用 2026-07-24 名單回測 2021–2026 屬前視偏差。比較「固定名單 + caveat」與「按年度換名單」的成本與偏差緩解效果。

## Phase 5：五年回測（閘門：Phase 4 完成）

- 資料區間延伸至五年，lookback 維持 252，樣本外 ≈ 1,000 日（99% 預期違約 ~10 次，檢定力約為現況兩倍）。
- 等權重與市值權重雙軌。
- 涵蓋 regime 需包含 2022 升息熊市與現有三個壓力期（2024/08、2025/04、2026/03）。
- 此階段才允許做最終 challenger 輪替決議。

---

## 升級門檻（challenger → primary）更新版

在原有門檻（數值超標率、NaN/Inf、效能、Redis 健康）之外新增：

1. **DM p < 0.10**（對 primary 的 QL 差異，等權重與市值權重至少一組達標且另一組不顯著劣化）。
2. 子期間排名穩定（兩半子樣本不翻轉）。
3. 近單根擬合比例 < 5%（variance targeting 後）。
4. 五年回測完成前，任何 challenger 不得輪替為 primary。

## 執行順序總覽

```
Phase 0  等權重回測            （零資料工程，最先做，可能改寫模型結論）
Phase 1  DM + 子期間 + 重疊分析 （純統計，半天～一天）
Phase 2  Ensemble 50/50         （無新模型，可能消滅分層需求）
Phase 3  Variance targeting     （小改動，一天）
Phase 4  Adjusted close 規劃    （文件 only）
Phase 5  五年回測               （gated）
```

## 產出格式

延用前次測試總結格式，新增：DM p-value 矩陣、子期間排名表、ensemble 指標列、variance targeting 前後對比。challenger 建議只允許三種結論：
(a) 某模型在 DM p < 0.10 下勝出；(b) 打平，依 parsimony 選對稱 GARCH；(c) ensemble 勝出。
