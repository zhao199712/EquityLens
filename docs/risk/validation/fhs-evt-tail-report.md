# FHS GPD 尾部延伸：研究 challenger 評估

日期：2026-11-05
程式：`src/EquityLens.Mathematics/src/equitylens_mathematics/research/fhs_tail.py`
輸出：`docs/risk/validation/fhs-evt-tail/fhs_evt_tail_summary.json`
前置：`es-backtest-report.md`（同一 seed 資料、組合與樣本外期間）

## 1. 動機與事先指定

ES 回測顯示市值組合 99% 尾部低估（Z1、McNeil–Frey 拒絕，tail ratio 1.25），
兩組各有 6 天實際報酬低於全部 10,000 筆模擬。假設：FHS 單日最大模擬損失受
窗口內最差殘差限制，GPD 尾部延伸可改善。

事先指定（看結果前）：

- 主設定 tail_prob = 0.10；0.05 僅為敏感度，不以結果挑選。
- 驗收：市值 99% Z1 與 McNeil–Frey 不再於 5% 拒絕，且等權組合不顯著惡化。

## 2. 方法

保留 production 的 joint-vector 重抽（同一 seed 抽出同一批殘差列，經驗 copula
不變），只替換每檔殘差左尾邊際：

- 每檔最小 k = ⌊0.10 × 252⌋ = 25 筆為尾部，第 26 小為門檻 u_i。
- 48 檔超額值合併估一個 GPD 形狀 ξ（限制 [0, 0.5]）；每檔尺度
  β_i = 平均超額_i × (1 − ξ)，保留各自的經驗平均超額。
- 抽到尾部排名 q 的殘差，改由 GPD 條件存活機率 (q + V)/k、V ~ U(0,1) 重抽。

單元測試斷言：非尾部樣本與 production 逐筆相等；尾部可超出歷史最小殘差。

## 3. 結果

ξ 每日估計：中位數 0.027，10%/90% 分位數 0 / 0.224，從未觸及上限。

## 4. 判讀

**未通過事先指定的驗收。** 市值 99% Z1 p=.013、McNeil–Frey p=.042 仍在 5%
拒絕；等權 99% QL 顯著惡化（p=.011）。改善集中在市值 97.5%（FZ0 p=.002，
Z2 不再拒絕）與超出支撐日數（6 → 3）。敏感度 tail_prob=0.05：市值 99% Z1
p=.027 仍拒絕、McNeil–Frey p=.056 勉強不拒絕，等權 99% QL 惡化不顯著
（p=.177），超出支撐日數 6 → 2；驗收仍未通過。依事先指定，不以敏感度結果
改選主設定。

### 4.1 為什麼幫助有限

- **殘差尾部已近指數型。** GARCH-t 過濾後 ξ 中位數僅 0.027，GPD 外推幅度
  小；平均 ES 只增加 1–4%。
- **崩盤日的問題在波動水準，不在尾部形狀。** 2025-04-07 等日子的標準化
  衝擊遠超任何合理尾部；根源是 GARCH 尚未上調波動，與 C_ES 拒絕同源，
  EVT 無法修正（C_ES 幾乎不變）。

### 4.2 新發現：production 1 日分配只有 252 個不同值

Joint-vector FHS 對所有資產抽同一列殘差、乘固定的明日波動，因此 1 日組合
分配只有 lookback 天數個不同值；10,000 次模擬只是重複抽樣。以 5 檔 fixture
驗證：10,000 筆中僅 252 個不同值；99% VaR 以下僅 3 個不同情境（VaR 情境
重複 36 次），97.5% 僅 7 個。

後果：

1. **99% ES ≈ 最差 2–3 個歷史日的平均**，估計變異大，且無法外推。
2. **ES 與 breach 定義內部不一致。** ES 取 `≤ VaR`（含大量 VaR 情境重複），
   breach 取 `< VaR`。在模型自身分配下，Z1 虛無平均為 −0.041（97.5%）與
   −0.074～−0.081（99%），Z2 虛無平均 +0.04～+0.135；即使模型完全正確，
   breach 日損失也平均比 ES 深 4–8%。EVT 加入連續抖動後虛無平均回到約 0，
   這也是等權 99% Z1 統計量改善、p 值反而下降的原因：比較基準不同。
3. 跨模型比較 Z1/Z2 時必須以各自虛無分配為基準，不能直接比統計量。多日
   路徑每天重抽且更新波動，不受此限制。

## 5. 結論與建議

- **不推進 EVT 尾部延伸至 production。** 未達驗收，且在等權 99% 有顯著代價。
- **優先處理反應速度**（VT-GJR、實現波動輸入或崩盤日保守上調），驗收以
  C_ES 與市值 99% Z1/McNeil–Frey 為準。
- **ES 定義一致性**為低成本修正候選：1 日分配加入連續化（例如核平滑或
  與本研究相同的區間抖動），或 ES 與 breach 採一致不等式。需另行驗證對
  VaR 回測與 API 數值的影響後再決定。
