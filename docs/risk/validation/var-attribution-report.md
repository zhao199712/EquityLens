# Production VaR 頻率偏高與違約集中：歸因分析

日期：2026-11-05
資料：私有 seed `seed-v3-20261105`，eval 匯出 `long9`（5,375 樣本外日，2004-12 起）、`top10`（1,817 日，2019-05 起）
程式：`src/EquityLens.Mathematics/src/equitylens_mathematics/research/attribution.py`
輸出：`docs/risk/validation/var-attribution/`
前置：`history-v3-es-evt-report.md`

## 1. 摘要

1. **VaR 頻率偏高，主要來自有限樣本分位數偏誤，不是模型錯誤。** Production 從
   252 個情境取最近秩分位數；即使模型完全正確，違約率也是 5.19%、2.70%、
   1.20%（非 5%、2.5%、1%）。八組觀察違約率與此理論值皆無顯著差異；改用無偏
   分位數後，Kupiec 全部通過。
2. **先前「ES 頻率加深度低估」的證據大多無效。** Z1、Z2 與模型自身虛無分配的
   U_ES，在「完全正確的有限情境 FHS」模擬中，T=5,375、97.5% 時誤拒率分別為
   50%、88%、100%。改用與分配無關的可交換虛無分配後，U_ES 十二組只有一組
   拒絕。
3. **違約集中是唯一穩健的缺陷。** 在可交換虛無分配下仍顯著；違約集中出現在
   「近 5 日實現波動遠高於預測波動」的日子，與預測波動的高低無關，也與參數
   重估時點無關。
4. **分散組合的變異數預測偏低 8–18%。** 只在等權組合出現，集中組合沒有。

## 2. 事先指定的假說

| 代號 | 假說 | 檢驗 | 判定準則 |
|---|---|---|---|
| H_A | 有限樣本分位數偏誤 | 正確模型下 production 最近秩 VaR 的精確違約率；改用 Weibull（p(n+1)）分位數重算 | 觀察違約率與理論值差異不顯著（p > .05），且無偏 VaR 通過 Kupiec |
| H_B | 變異數水準偏差 | E[r²]/E[σ̂²]，block bootstrap 90% CI；Mincer–Zarnowitz | 比值 CI 包含 1 則排除 |
| H_C | 參數過時 | 依距上次重估天數分組；每 5 日重估變體 | 分組無差異且變體未改善則排除 |
| H_D | 殘差庫長度 | lookback 504 變體 | 頻率與集中檢定的變化 |
| H_E | 跨資產相依 | 組合單變量 VT-GARCH-FHS 變體 | 同上 |
| H_F | 違約集中機制 | 前一日違約後的條件違約率；依近 5 日實現波動 ÷ 預測波動、依預測波動分五分位 | 分組違約率差異的 χ² 檢定 |

每個變體只改一個元件，其餘與 production 相同（同 seed 標籤；基準變體與
`history-v3-es-evt-report.md` 的預測逐日相同）。

### 2.1 正確模型下的精確違約率

Production 一日分配是把 n 個情境各重抽約 10,000/n 次。最近秩 VaR 取累積
抽樣數首次達到 ⌈(1−c)·10,000⌉ 的第 j 個情境（照 `engine.nearest_rank`
的算法，包含浮點捨入）。模型正確時，新報酬與情境可交換，嚴格低於第 j 小
情境的機率為 j/(n+1)，與真實分配無關。以多項分配模擬抽樣數取平均：

| 情境數 n | 95% | 97.5% | 99% |
|---|---|---|---|
| 252 | 5.19% | 2.70% | 1.20% |
| 504 | 5.10% | 2.60% | 1.11% |

單元測試以「每日新情境庫、新報酬來自真實分配」的模擬驗證此值。

### 3.2 ES 檢定的虛無分配問題

先前 ES 檢定以「實現報酬從模型的重抽分配抽出」為虛無假設，等於假設 252 個
情境就是真實分配，忽略情境庫本身是有限樣本。以「每日新情境庫、新報酬來自
真實 t(5) 分配」的正確模型模擬（8 組，T=5,375，97.5%）：

| 檢定 | 誤拒率 |
|---|---|
| U_ES（模型自身虛無） | 100% |
| Z2 | 88% |
| Z1 | 50% |
| McNeil–Frey | 0% |
| C_ES(5)（模型自身虛無） | 0% |

改用可交換虛無分配（新報酬在 n 個情境中的排名均勻分布於 n+1 個位置，與真實
分配無關）後，U_ES 與 C_ES 在同類模擬中誤拒率為 5%–7.5%。Z1、Z2 涉及損失
數值，沒有分配無關的虛無分配，**本報告不採用其結論**。

近 5 日實現 ÷ 預測波動的五分位切點約為 0.63、0.80、0.95、1.17（long9）。
實現波動以 t−5 至 t−1 的實際報酬計算，在預測當下已知。

**H_C 判定：排除。** 距重估天數分組無差異（p .46–.92），每 5 日重估也沒有改善
頻率或集中（見 3.5）。

**H_F 判定：成立（相關性證據）。** 前一日違約後的違約率是平時的 1.7–4.6 倍。
近 5 日實現波動顯著高於預測時（最高五分位，比值 > 約 1.17），違約率在 95%
為最低五分位的 1.6–2.9 倍，在 99% 為 2.4–7.5 倍；預測波動本身的高低與違約率
無關（p .16–.86）。即：**模型的條件波動對近期實現波動上升反應不足**，與違約
集中一致。這是相關性證據，尚未以修正模型驗證因果。

括號內為該變體情境數下的理論違約率。

- **每 5 日重估（H_C）**：頻率與集中幾乎不變，排除參數過時。
- **lookback 504（H_D）**：違約率略降，主要因理論偏誤變小（n 加倍）；集中仍在
  95%／97.5% 顯著，99% 略改善。不是主因。
- **組合單變量模型（H_E）**：快照權重差異不大；等權反而更差（99% 1.53% vs
  1.40%）。Joint-vector 對分散組合有幫助，跨資產建模不是問題來源。

## 4. 修正先前報告

- `history-v3-es-evt-report.md`、`es-backtest-report.md`、兩份 EVT 報告中，以
  Z1、Z2、模型自身 U_ES 得出的「ES 頻率加深度低估」結論撤回；VaR 頻率偏高
  應歸因於第 3.1 節的有限樣本偏誤，而非模型錯誤。
- 違約集中（Christoffersen、C_ES）結論維持。
- EVT 驗收準則中的 Z1 部分無法判讀；EVT「不建議推進」的結論改以 QL/FZ0 無
  顯著差異為依據，仍成立。
- 先前用於驗證檢定大小的 fixture 讓實現值從同一批情境抽出，無法發現此問題；
  新測試改用每日新情境庫與真實分配。

## 5. 限制

- 倖存者與前視偏誤、快照權重、資料未經獨立稽核，同 `history-v3-es-evt-report.md`。
- 缺價政策沿用 eval（剔除），與 production（沿用前值）不同。
- H_F 為相關性證據；未修正參數估計誤差；單一模擬種子集合。
- 可交換虛無分配假設標準化殘差在時間上可交換；GARCH 過濾誤差會使其近似成立。

## 6. 建議

1. **VaR 分位數偏誤**：最低成本的修正是改用無偏分位數（Weibull 位置或在情境
   間內插），或在說明中揭露名目信賴水準的實際違約率。會改變 API 數值，需先
   評估；建議先開獨立 PR 討論。
2. **違約集中**：以 H_F 為依據設計 challenger，例如讓條件波動納入近期實現
   波動，或 GJR 類不對稱反應。驗收以 C_ES（可交換虛無）、Christoffersen 及
   「實現／預測波動高五分位的違約率」為準，事先指定。
3. **分散組合的變異數偏低**：以等權組合為對象，檢驗相關性動態（例如重啟 DCC
   評估，以 v3 長歷史與 H_B 指標驗收）。
