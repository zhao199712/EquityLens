# 投組數字口徑（R22）

同一投組的數字未必可直接比較。此輪保留既有計算公式，修正錯誤標籤並揭露口徑，沒有以其中一個數字取代所有畫面。

| 資料來源 | 權重與現金 | 報酬、波動與回撤 | 期間／樣本 |
|---|---|---|---|
| Risk API 同步結果 | 當期已定價市值固定權重，不含帳戶現金；缺歷史標的不重配，未配置權重零報酬 | 個股對數報酬加權；EWMA 年化；回撤由該報酬序列重建 | API 請求範圍內的共同價格日；每期限歷史 VaR／ES 使用各自滾動視窗 |
| Agent 本地補算 | 現有股數固定，不含現金、不換匯；貢獻／集中度另取期末固定權重 | 股數乘歷史價格重建組合，簡單報酬的樣本標準差年化；回撤取同一歷史價值序列。風險貢獻使用對數報酬協方差 | 最多 253 個共同價格日、252 筆日報酬，保存實際首尾日期 |
| Agent 情境比較 | 同一快照，固定權重，現金零報酬；減碼轉現金或轉入既有持股 | 簡單報酬；同一協方差、信心、期限；各情境及原組合都經同一 Evaluate 函式 | 同快照的共同交易日；至少 120 筆，保存 inputHash／日期／觀測數 |
| 已存 Risk Run | 沿用來源 inputHash、algorithmVersion 與方法中繼資料 | 來源歷史欄位才能填歷史 VaR／ES；模型模擬分位數不能冒充歷史估計 | 保留請求快照；舊結果未保存的權重、現金或樣本口徑明示未知 |
| 帳戶績效／歸因 | 帳戶估值服務依交易及現金流計算；持股歸因另以期初股數市值配置 | 帳戶 TWR／基準報酬與固定配置的假設績效不同，不能以差值聲稱風險改善 | 診斷請求期間；歸因覆蓋另有 complete／partial |

API 新增 `measurementBasis`，Agent 每項指標保留其 provenance，Risk Run 回應增加唯讀 `inputSnapshot`。舊結果不補造口徑。前端在數字旁提供期間、方法、現金與樣本說明；情境差異只相對同表原組合。模型模擬路徑回撤、歷史重建回撤與帳戶實際回撤是不同統計量。

不同幣別且未換匯的 Agent 補算資料附警告，不應直接比較；情境快照則明確拒絕不同幣別。既有結果是否通過回測仍由品質狀態決定，口徑揭露不代表模型驗證通過。
